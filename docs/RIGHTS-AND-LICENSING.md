# 权利与许可边界

## 双许可结构

- 软件代码、项目文件、测试和工具：MIT License，见仓库根目录 `LICENSE`。
- 确认原创的文档和教学内容：CC BY 4.0，见 `LICENSE-CONTENT.md`。
- 第三方依赖、译文、引文、书目、商标和链接材料：仍受各自权利与条款约束，见 `THIRD-PARTY-NOTICES.md`。

CC BY 4.0 只适用于项目持有权利的原创表达和结构，不会因内容保存在同一 JSON 文件中而自动覆盖其中的第三方材料。链接、版本和 locator 也不代表项目获得了来源作品的再许可权。

## 贡献边界

贡献者必须有权按对应许可证提交材料。现代译本、出版社页面、百科条目和学术著作应以简洁转述、书目信息和精确 locator 为主，不应复制大段正文。无法确认许可时，应保留来源引用并缩窄项目内表达。

## 公开发布前持续审计

首次 Release 前仍应复核：

1. 是否存在超出合理引用或适用例外的第三方正文；
2. attribution、版本、译者和稳定链接是否准确；
3. package license 与 notice 是否随分发物保留；
4. 新增图片、字体、数据或媒体是否具有明确权利来源。

本文件记录项目采用的许可边界，不构成针对具体司法辖区的法律意见。
