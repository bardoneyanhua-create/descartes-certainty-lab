# 无障碍能力与验证边界

## 设计目标

项目面向无法或不便依赖视觉操作的学习者，界面设计关注可朗读名称、键盘导航、焦点顺序、状态反馈、文本替代和不依赖颜色的表达。

## 已有机器证据

- 内容和控件的静态无障碍检查已纳入回归流程。
- 基础构建与测试可以 headless 运行，不要求启动产品窗口。
- 学习内容使用结构化标题、段落、问题、选项和反馈。
- 公开测试不读取剪贴板、真实凭据或辅助技术私人数据。

## 尚未完成的人工验证

以下流程目前不能声称已经通过：

- Narrator 端到端朗读和操作；
- NVDA 端到端朗读和操作；
- UI Automation 树人工核查；
- 物理键盘完整导航；
- 产品窗口中的焦点恢复、WebView2 和运行时交互体验。

公开 Release 应明确保留这些限制。来自真实读屏用户的反馈将作为优先维护证据，但不得虚构测试结果或代表性。

## 报告无障碍问题

请尽量提供辅助技术名称与版本、Windows 版本、起始页面、按键顺序、实际朗读结果和期望结果。不要提交账号密码、验证码或其他敏感信息。
