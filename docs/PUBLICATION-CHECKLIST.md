## 建议首发策略

推荐将首个公开版本标为 **preview**，而不是宣称全部哲学引用已经闭合。README 和 Release 应明确：

- 应用、schema、构建和 portable artifact 已通过机器复核；
- Narrator、NVDA、UIA 和物理键盘端到端测试仍需要真实用户证据；
- 结构化引用正在持续校勘，首批维护 Issue 已准备；
- 第三方材料不受项目 CC BY 4.0 重新授权。

## 活动申请门

只有在仓库已经公开、存在真实维护活动和可验证采用证据后，才提交 Codex for Open Source 申请。形式上公开但没有维护记录的仓库不应被描述为活跃项目。
